“Library မှာ သိမ်းမယ်” က ဒီ tab ထဲမှာပဲ သိမ်းပါတယ် — tab ပိတ်ရင် ပျောက်သွားပါမယ်။

ကိုယ်ပိုင်အသံ (Clone) — အသံစမ်းသပ်မှု

ကိုယ့်အသံ နမူနာကို အသံသွင်း / ဖိုင်တင်ပြီး သိမ်းပါ။ သိမ်းထားတဲ့ အသံက Studio အသံစာရင်းထဲမှာ ပေါ်လာပါမယ်။ ရိုးသားစွာ ပြောရရင် ဒီ public စာမျက်နှာမှာ AI clone အတိအကျ မရသေးပါ — နမူနာရဲ့ pitch ကို တိုင်းပြီး စက်အသံကို အဲဒီ pitch နဲ့ နီးအောင် ချိန်ပေးတာပါ။ အတိအကျ clone လိုရင် server ဗားရှင်းပဲ လိုပါတယ်။

အသံသွင်းဖို့ ခွင့်ပြုချက် တောင်းပါမယ်။

Link ဘာသာပြန် — Link တစ်ခုပဲ လိုပါတယ်

ဗီဒီယို link တစ်ခုတည်း ထည့်ရုံပဲ — ခေါင်းစဉ် / မှတ်စု ဖောင်ဖြည့်စရာ မလိုပါ။

Transcript / Caption ထည့်ပါ

ဒီ static စာမျက်နှာက TikTok / YouTube ထဲက transcript ကို တိုက်ရိုက် ဖတ်လို့ မရပါ — server ဗားရှင်းမှသာ ရပါတယ်။ ဒါကြောင့် ဗီဒီယိုအောက်က caption / transcript ကို ဒီမှာ ကူးထည့်ပေးပါ။ ကူးထည့်တဲ့ စာသားအတိုင်းပဲ အကျဉ်းချုပ် မူကြမ်း လုပ်ပေးပါမယ် — အပိုအကြောင်းအရာ အသစ် မထည့်ပါ၊ အဆုံးမှာ ပိတ်စာကြောင်းလည်း မထည့်ပါ။

Library — သိမ်းထားတာများ

ဒီ tab ထဲမှာပဲ သိမ်းထားပါတယ်။ စာမျက်နှာ ပြန်ဖွင့်ရင် / tab ပိတ်ရင် ပျောက်သွားပါမယ်။

ဘာမှ မသိမ်းထားသေးပါ။ Studio မှာ စာရိုက်ပြီး “Library မှာ သိမ်းမယ်” ကို နှိပ်ပါ။

ဝါးတဲ့ အကွက် — ပုံတစ်ပုံစာ စမ်းသပ်ခြင်း

မူရင်းပုံ (frame) တစ်ပုံ တင်ပါ။ အကွက်ကို လက်နဲ့ ဆွဲရွှေ့နိုင်ပါတယ်၊ အဖြူစက်လေးကို ဆွဲပြီး ကျုံ့ / ချဲ့နိုင်ပါတယ်၊ “အပေါ်တိုး” နဲ့ အပေါ်ရွှေ့နိုင်ပါတယ်။ အကွက်ထဲက အပိုင်းက live ဝါးနေပါမယ်။ ပုံတစ်ပုံစာပဲ ဖြစ်ပါတယ် — ဗီဒီယိုတစ်ပုဒ်လုံး ဝါးပြီး MP4 ထုတ်တာက server ဗားရှင်းမှ ရပါတယ်။

ပုံမတင်ရသေးပါ — အပေါ်ကနေ ပုံတစ်ပုံ ရွေးပါ။

ဝါးမယ့်အကွက် — ဆွဲရွှေ့လို့ရပါတယ်

အကွက် အနေအထား — မရွေးရသေးပါ။

ဒီ public စာမျက်နှာအကြောင်း — ရိုးသားစွာ

ဒါက server မရှိတဲ့ static စာမျက်နှာပါ။ အသံက ဖုန်း / ကွန်ပျူတာထဲက စက်အသံ (device voice) ကို pitch နဲ့ အမြန်နှုန်း ချိန်ပြီး သုံးတာပါ — Google Studio / Azure ရဲ့ အသံအစစ်၊ AI clone အတိအကျ၊ link ကနေ transcript အလိုအလျောက် ဖတ်တာ၊ ဗီဒီယို dub + ပေါင်းတာ၊ စာတန်း burn-in တို့ ဒီမှာ မပါပါ။ အဲဒါတွေက server ဗားရှင်း (Muse Library ထဲက Voice Application) မှာသာ ရပါတယ်။

ဗီဒီယို ၂ နာရီခွဲအထိ အပိုင်းလိုက် dub + ပေါင်းတာကလည်း server မှာ လုပ်ရတာပါ — ဒီစာမျက်နှာက အပိုင်းခွဲအစီအစဉ်နဲ့ စာတန်း (.srt) ကို ကြိုတင်ပြင်ပေးနိုင်ပါတယ်။ Telegram ပို့တာမျိုး ဒီစာမျက်နှာမှာ မပါပါ။
